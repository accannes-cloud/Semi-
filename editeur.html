Éditeur du site

Choisis une page, puis clique directement sur un texte ou une photo pour la modifier.

Publication directe (une seule fois à configurer) : connecte l'éditeur à ton dépôt GitHub avec une clé d'accès personnelle, limitée à ce seul dépôt.
  1. Sur GitHub : Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access → « Only select repositories » → choisis ton dépôt
  3. Permissions → Contents → coche Read and write
  4. Génère, copie la clé (elle commence par github_pat_…) — colle-la ci-dessous

Comment ça marche : clique sur un texte pour le modifier (une petite croix ✕ apparaît au-dessus pour le supprimer), ou passe la souris sur une photo pour la changer ou la retirer. Utilise le + entre les sections dans l'aperçu pour en ajouter une à l'endroit voulu, et les puces au-dessus pour réordonner, masquer ou supprimer une section entière. Clique « 💾 Enregistrer » pour publier directement en ligne.
